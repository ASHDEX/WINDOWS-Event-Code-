# Windows Event Code Reference

This repository provides a curated reference of **Windows Security Event Codes** and their associated descriptions for use in log analysis, incident response, and detection engineering.

Windows Event Logs are a foundational source of security telemetry across enterprise environments. Understanding event codes and what they represent helps defenders build detection logic, investigate incidents, and automate alerting.

---

## 🚀 What This Is

This project includes:
- A categorized list of Windows Security Event Codes  
- Plain-language descriptions of events  
- Context for common security-relevant patterns  
- A quick lookup reference to support detection and investigation work

This is intended for security analysts, detection engineers, incident responders, and threat hunters.

---

## 🧠 Why It Matters

Windows Event Logs are generated by all Windows machines and contain rich telemetry that defenders use to:
- Detect unauthorized access attempts  
- Track process execution and persistence  
- Identify privilege escalation  
- Investigate lateral movement  
- Understand user behavior  
- Correlate events during incident response

This reference makes it easier to interpret raw event logs and build meaningful detection and alerting logic.

---

## 📁 What’s Included

Each entry in this repository includes:
- **Event Code (e.g., 4688, 4625)**  
- **Event Title / Description**  
- **Security relevance / common use cases**

Example categories:
- Authentication events  
- Process creation & termination  
- Privilege use  
- Account management  
- System integrity

Feel free to browse the files or use the search feature to quickly locate event codes you need.
